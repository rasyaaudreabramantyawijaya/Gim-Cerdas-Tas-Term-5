# Mountain sanctuary — art direction

The user rejected floating columns and photo-only backdrops. The runtime title environment is generated 3D scenery in ScenicBackdrop.cs: sculpted ground mesh, mossy crags, grounded masonry arch, pine geometry, flowing-water shader, curved waterfall meshes, spray particles, reflective pool, HDR sky lighting, animated cinematic camera and post-processing. No concept image is loaded by runtime code.

`mountain-waterfall-concept.png` is an original reference generated with the built-in imagegen tool on 21 October 2026, before the user clarified the 3D-only preference. It remains a design reference, not a screenshot or evidence of runtime fidelity. Actual Unity captures must be judged separately.

## Generation prompt (built-in mode, no API CLI)

Use case: stylized-concept. Asset type: original high-quality Unity fantasy adventure game main-menu and loading-screen background, cinematic wide landscape 16:9. Primary request: a believable mountainous dungeon valley with a cascading waterfall, suitable for the game Dungeon Hunter: Relic of Veyr. Scene: an ancient weathered stone dungeon entrance physically carved into a colossal mossy mountain cliff, a winding grounded stone path leading from the foreground to its turquoise rune-lit arched gate; tall waterfalls cascade down the right cliff into a clear deep teal pool; layered distant mountains, grass, ferns and pine forests, drifting low mist, warm early sunlight reflecting naturally on water and wet stone. Composition: expansive immersive scenic landscape, focal dungeon gate and waterfall in the right two-thirds; left third has dark shaded pine trees and understated mist with clean low-detail negative space to accommodate the existing game title and buttons. Style: polished realistic fantasy environment key art with cinematic depth, physically plausible grounded architecture and detailed rock, not cartoon, premium PC adventure atmosphere. Palette: deep pine green, teal water, cool slate rock, warm pale gold sunlight. Constraints: NO floating pillars or floating structures, no people, no lettering, no text, no logos, no watermark, no UI. Every building and path clearly grounded in terrain. Landscape image full bleed.
