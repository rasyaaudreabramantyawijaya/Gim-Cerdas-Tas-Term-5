## Cara menggunakan

Buka subfolder proyek yang ingin digunakan. Jalankan program atau buka proyek dari direktori tersebut agar jalur aset dan konfigurasi tetap sesuai.

Di Unity Hub, pilih Add project from disk lalu pilih satu subfolder yang berisi `Assets`, `Packages`, dan `ProjectSettings`. Setiap subfolder merupakan proyek terpisah. Repo ini private karena mencakup proyek yang sebelumnya private.

## Riwayat dan migrasi

- Riwayat default branch sumber tersedia dalam ancestry `main`.
- Branch sumber disimpan sebagai `history/<repo>/<branch>`.
- Tag sumber, jika ada, disimpan sebagai `source/<repo>/<tag>`.
- Commit, URL, dan tree Git asal dicatat di [MIGRATION.json](MIGRATION.json).
- Tanggal migrasi: 10 Oktober 2026.
